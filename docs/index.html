01 · Overview

What this extension does

AniWorld AP is a fork of Ziegel8171's extension. It parses the anime, season and episode from the aniworld.to page, asks the AniSkip API for the segment timestamps of that episode, and renders them as skip controls on the VOE player — in this fork with playback speed, a next-episode shortcut and a redesigned control set.

Version 1.7.0 — see releases
Platform Firefox 142 or newer, desktop and Android. Firefox only — it uses the browser.* API.
Runs on aniworld.to and the VOE player iframe it embeds
Data sources AniSkip for skip segments, AniList (with a Kitsu fallback) for MyAnimeList matching
Storage browser.storage.local only — settings and cached lookups, nothing leaves the browser
License MIT
02 · Fork changes

What the fork adds

Everything below is specific to this fork. The base skipping logic and the AniSkip panel come from upstream; the player controls, speed handling and defaults were reworked here.

added

Speed control

Playback speed from 0.25× to 5× with −/+ buttons next to the skip control. Click the readout to jump back to 1×. Speed can persist across episodes.

added

Next episode

A next-episode button inside the player bar, plus automatic navigation when an episode ends. Both are on by default; auto-navigation can be switched off on its own.

added

Always-visible skip button

The skip button stays visible for the whole episode. When no opening or ending is playing, it jumps 90 seconds ahead instead of disappearing.

added

Recap segments & skip offset

Recap detection on top of OP/ED, with its own timeline colour, and a skip offset (−5 s to +5 s) so the skip can land slightly before or after the segment end.

changed

Redesigned overlay

Info toggle at the top right opens the AniSkip panel; skip, speed and next-episode controls sit together at the bottom. The skip button now carries the segment type as a badge.

changed

Two themes, AniWorld first

The AniWorld theme (petrol background, blue accent) is the default. Classic keeps the original pink/violet look. Progress-bar marker colours are configurable per segment type.

! Defaults are conservative. Auto-skip for OP, ED and recaps is off until you enable it, and so are volume/position memory — VOE already remembers those. The fork only adds what the player does not do itself.

05 · How it works

From page load to skipped intro

The extension is split into a page script on aniworld.to, a persistent background script that owns all network access, and a player script inside the VOE iframe.

  1. Detect the episode. aniworld.js reads anime, season and episode number from the breadcrumbs and URL, and applies your saved language preference.
  2. Resolve the MAL ID. The background script looks the title up on AniList (with Kitsu as a fallback), keeps only entries that map to MyAnimeList, and caches the match — the same anime is only searched once.
  3. Fetch skip times. Skip segments for the episode are requested from the AniSkip API through the background script — the content script never talks to the network directly.
  4. Inject the overlay. When the VOE frame loads, content.js and styles.css are injected into it and the controls, markers and panel are built.
  5. Skip and continue. Segments are skipped on time or on click; at the end of an episode a postMessage asks the page script for the next one.

Files

  • src/defaults.js — the single source of truth for settings
  • src/background.js — API proxy and iframe injection
  • src/aniworld.js — page parsing, navigation, language
  • src/content.js — player overlay and skip logic
  • src/popup.* — settings UI and translations

Privacy

Settings, cached lookups and playback state stay in browser.storage.local, including a random installation ID that is only sent along when you submit skip times yourself. There is no analytics, no account and no server of our own — just requests to the public AniSkip, AniList and Kitsu APIs.

06 · Permissions

Why the extension asks for this

Everything is requested up front in the manifest, so Firefox shows the full list on install.

Permission Reason

activeTab Let the popup push changed settings into the tab you are watching, without a reload.
webNavigation Notice when the VOE player iframe finishes loading, so the overlay can be injected.
<all_urls> Inject into the player subframe — its hostname changes between mirrors.
https://api.aniskip.com/* Fetch skip segments and submit timestamps.
07 · Installation

Install it

The signed build is published on addons.mozilla.org and updates itself. Temporary installs are only for testing and disappear when Firefox restarts.

recommended

Signed build for Firefox desktop and Android, with automatic updates.

Open the listing

Make sure you land on aniworld-autoplay-fork — the upstream aniworld-autoplay is a different add-on.

testing

From a release ZIP

Temporary add-on, removes itself on restart.

  1. Download and extract the .zip from the latest release.
  2. Open about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on and pick the extracted manifest.json.
i Requirements: Firefox 142+ and access to aniworld.to. The extension only activates inside the VOE player iframe — on other sites it does nothing.
08 · Development

Build and release

No bundler, no TypeScript, no test runner: vanilla JavaScript, loaded straight from manifest.json. Node is only needed for packaging.

Local development

  1. Edit the files under src/.
  2. Open about:debugging#/runtime/this-firefox → Load Temporary Add-on → manifest.json.
  3. Reload the add-on after every change and refresh the aniworld.to page.

Packaging

# web-ext must be installed globally: npm install --global web-ext
# Windows
powershell -File pack.ps1

# Linux / macOS
./pack.sh

Both scripts stamp the current version and date into src/popup.html, build a ZIP into web-ext-artifacts/ and skip docs/.

Releases

Bump version in manifest.json and push to main. The workflow compares the previous and current version and — when it changed — creates the matching v<version> tag and a GitHub Release with the built ZIP. If AMO_ENABLED and the AMO secrets are configured, the signed build is published as well. 

# manifest.json → "version": "1.7.1"
git add manifest.json
git commit -m "bump version to 1.7.1"
git push origin main
